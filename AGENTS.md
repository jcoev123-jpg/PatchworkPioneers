# Patchwork Pioneers

## Project

Patchwork Pioneers is a small 2D deck-building roguelike in Godot 4.7.2 using GDScript and the Compatibility
renderer: three heroes in a line (front, middle, back) share one hand of cards, fight through a short branching map
and face a boss. Main scene: `res://scenes/app.tscn`. Design: `.review/full_game/GAME_DESIGN.md` (scope and numbers)
and `.review/full_game/MILESTONES.md` (build order) in the main checkout.

## Running tests

Run from the repository root. Run this once first to refresh the class cache:

```sh
godot --headless --path . --import
```

Then run each test:

```sh
for t in tests/*_test.gd; do godot --headless --path . -s "res://$t" || echo "FAIL $t"; done
```

A test passes when it exits 0 and prints no "SCRIPT ERROR", "Parse Error" or "Failed to load script".

## Rules

- Every change must keep all tests passing; add or update deterministic tests for new behaviour. Never weaken or
  delete tests to make them pass.
- Rules live in plain GDScript classes with no scene dependencies (combat, deck, map, run), driven by data
  resources in `data/`. Views only display state and send player actions.
- One seeded RandomNumberGenerator per run; never use wall-clock time or unseeded randomness in rules or tests.
- Never create or edit PNG/art files. Images under `assets/paper/` are generated by a separate pipeline. Code must
  fall back to a drawn placeholder when an image is missing; tests must never assert that an art file is ABSENT.
- Commit Godot-generated sidecars (`*.import` for new assets, `*.gd.uid` for new scripts) together with the files
  they belong to.
- Gameplay numbers come from the design docs and `data/*.tres`. Do not change balance values unless the task says so.
- UI targets 1280x720; every action must be reachable by mouse and keyboard.
- Do not leave scratch, probe or debug files in the repository. Audio is out of scope.

## Art direction

Patchwork cut paper and felt, stitched together (see `.review/full_game/ART_STYLE.md`): one static image per actor,
animated procedurally like a paper puppet (breathing, lunge, hit flash, fall), with linear texture filtering.
